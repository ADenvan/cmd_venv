🎯 Как работает сценарий пользователя:
Шаг 1: Админ входит
http://127.0.0.1:8000/auth/login/
→ Django проверяет логин/пароль
→ Создаёт сессию
→ Перенаправляет на дашборд
Шаг 2: Добавление сотрудника
http://127.0.0.1:8000/employees/create/
→ Админ заполняет форму HTML
→ Нажимает "Сохранить"
→ Django создаёт запись в БД (Employee)
→ Django создаёт Contract с зарплатой
→ Перенаправляет на список сотрудников
Шаг 3: Создание периода расчёта
http://127.0.0.1:8000/payroll/periods/create/
→ Админ выбирает год/месяц
→ Django создаёт PayPeriod
→ Django автоматически создаёт 2 части (1-15, 16-31)
→ Показывает экран расчёта
Шаг 4: Расчёт зарплаты (ВАЖНО!)
http://127.0.0.1:8000/payroll/periods/1/
→ Админ нажимает кнопку "Рассчитать"
→ Django вызывает PayrollCalculator.calculate()
→ Python выполняет все формулы:
   - Для каждого сотрудника
   - Для каждого периода (1-15, 16-31)
   - Считает по формуле из контракта
   - НДФЛ 13%
   - Создаёт Payslip (расчётный листок)
→ Показывает результат

🧪 Как это работает:
Админ открывает draft период
        ↓
Видит кнопку "Предпросмотр" рядом с "Рассчитать"
        ↓
Нажимает "Предпросмотр"
        ↓
Открывается модальное окно с loading spinner
        ↓
JS отправляет POST на /periods/ID/preview/
        ↓
Сервер считает зарплату для всех сотрудников (без save!)
        ↓
Возвращает JSON с данными
        ↓
JS отрисовывает таблицу с результатами
        ↓
Админ видит:
  - Сколько сотрудников
  - Общую сумму начислений
  - НДФЛ
  - К выплате
  - Детали по каждому сотруднику
        ↓
Если всё верно → нажимает "Подтвердить и сохранить"
        ↓
JS отправляет POST на /periods/ID/calculate/
        ↓
Сервер сохраняет расчёт в БД
        ↓
Страница обновляется, появляются расчётные листки
