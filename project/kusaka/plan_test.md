
# Технологии тестирования.
- WER (Word Error Rate — коэффициент ошибок слов)
    - используется для оценки систем распознавания речи.
- CER (Character Error Rate — коэффициент ошибок символов)
    - измеряет количество ошибок на уровне символов в транскрипции.
- MOS-тестирования
    - зависит от конкретных целей тестирования, типа системы и условий её применения.

## Ключевые цели

Построить production-ready voice assistant с end-to-end latency ≤ 1.8–1.9s.
Реализовать VAD-базированный barge-in, streaming LLM → TTS, sliding-window memory, и инструментальные вызовы (tool calls) с корректной обработкой ошибок и fallback.
Обеспечить модульность и расширяемость через архитектурные ADR-и, документацию и тестовую стратегию.
Встроить наблюдаемость (метрики, логи, tracing) и базовую безопасность.

## Исходные компоненты (как база)

ASR: faster-whisper (большие модели, turbo режим).
VAD: silero-vad (режим стриминга).
TTS: edge-tts (потоковая генерация).
LLM-оркестрация: LangGraph ( локальная/офлайн-модель 8B для рекурсивного диалога).
Оркестрация и паттерны: асинхронная конвейерная архитектура, очереди для VAD/ASR/LLM/TTS, мониторы барge-in, Sliding Window Memory, FAISS/RAG по потребности.
