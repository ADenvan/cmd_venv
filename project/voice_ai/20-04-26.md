Дай инструкцию по запуску проекта. пошаговый запуск проекта голосовой ассистент.



Режим A: Локальный голосовой ассистент (микрофон + динамики)
python -m src.cli.app run
Ключи:
- --mode button|wake_word|continuous
- --model <ollama_model>
- --whisper <tiny|base|small|medium|large-v3>
- --device cuda|cpu
- --log-level DEBUG

Режим B: Текстовый чат (без микрофона)
python -m src.cli.app chat

Режим C: API-сервер (WebSocket + REST)
python -m src.cli.app serve
Ключи:
- --host 0.0.0.0
- --port 8000
- --reload (автоперезагрузка при изменениях)
- --log-level DEBUG
После запуска:
- Swagger UI: http://localhost:8000/docs
- REST: GET /api/health, GET /api/config, CRUD /api/sessions
- WS чат: ws://localhost:8000/ws/chat/{session_id}
- WS голос: ws://localhost:8000/ws/voice/{session_id}

Пошаговая инструкция запуска voice_ai
Предварительные требования
1. Python 3.13+ установлен
2. Ollama установлен и запущен с моделью qwen2.5:7b
3. CUDA (опционально, для GPU-ускорения)
---
Шаг 1. Клонирование и venv
cd D:\Python-Project\asist\voice_ai
python -m venv .venv
.venv\Scripts\activate
Шаг 2. Установка PyTorch (с CUDA)
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
> Для CPU-only: pip install torch torchvision torchaudio
Шаг 3. Установка зависимостей
pip install -r requirements.txt
pip install -e .
Шаг 4. Установка модели Ollama
ollama serve          # запустить сервер (если не запущен)
ollama pull qwen2.5:7b   # скачать модель
Шаг 5. Настройка (опционально)
Создать .env в корне проекта для переопределения дефолтов:
OLLAMA_MODEL=qwen2.5:7b
WHISPER_MODEL=large-v3
WHISPER_DEVICE=cuda
ACTIVATION_MODE=wake_word
API_HOST=0.0.0.0
API_PORT=8000
LOG_LEVEL=INFO
---
