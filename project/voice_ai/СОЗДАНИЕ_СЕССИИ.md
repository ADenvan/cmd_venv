WebSocket: Текстовый чат — ws://localhost:8000/ws/chat/{session_id}
Для общения с LLM через текст, без микрофона. Session_id должен существовать (создайте через POST /api/sessions).
Подключение
import websockets
import json
async def chat():
    session_id = "20260421T154705Z"  # создайте через POST /api/sessions
    async with websockets.connect(f"ws://localhost:8000/ws/chat/{session_id}") as ws:
        # Отправить сообщение
        await ws.send(json.dumps({"type": "user_text", "content": "Привет!"}))
        # Получать ответы
        while True:
            msg = await ws.recv()
            data = json.loads(msg)
            if data["type"] == "assistant_token":
                print(data["content"], end="", flush=True)
            elif data["type"] == "assistant_done":
                print(f"\nПолный ответ: {data['content']}")
                break
            elif data["type"] == "error":
                print(f"Ошибка: {data['message']}")
                break
Протокол сообщений
Клиент → Сервер:
Тип	Формат	Описание
user_text	{"type": "user_text", "content": "Сообщение"}	Отправить текст (1–10000 символов)
Если отправить новое user_text пока LLM ещё генерирует — текущая генерация отменяется, придёт generation_cancelled, затем начнётся обработка нового сообщения.
Сервер → Клиент:
Тип	Формат	Описание
assistant_token	{"type": "assistant_token", "content": "ток"}	Потоковый токен LLM
assistant_done	{"type": "assistant_done", "content": "полный текст"}	Генерация завершена, полный ответ
generation_cancelled	{"type": "generation_cancelled"}	Предыдущая генерация отменена новым сообщением
error	{"type": "error", "message": "текст ошибки"}	Ошибка

WebSocket: Голосовой ввод — ws://localhost:8000/ws/voice/{session_id}
Полный голосовой пайплайн: аудио → VAD → STT → LLM → TTS → аудио. Только один клиент одновременно (PipelineLock). Session_id должен существовать.
Протокол
Клиент → Сервер:
Тип	Формат	Описание
Audio binary	Raw bytes (float32 PCM, 16kHz, mono)	Аудио-чанки по 500мс (8000 floats = 32000 bytes)
Interrupt	{"type": "interrupt"}	Прервать текущий ответ ассистента
Сервер → Клиент (JSON):
Тип	Формат	Описание
state	{"type": "state", "state": "LISTENING"}	Состояние пайплайна: IDLE, LISTENING, PROCESSING_STT, THINKING, SPEAKING
transcription	{"type": "transcription", "text": "..."}	Распознанный текст (результат STT)
assistant_token	{"type": "assistant_token", "content": "ток"}	Потоковый токен LLM
audio_start	{"type": "audio_start", "sample_rate": 48000, "format": "pcm_f32_le", "total_samples": N}	Начинается отправка аудио-ответа
Audio binary	Raw bytes (float32 PCM, 48kHz, mono)	Аудио-чанки ответа (по 4096 floats = 16384 bytes)
audio_end	{"type": "audio_end"}	Аудио-ответ полностью отправлен
audio_interrupted	{"type": "audio_interrupted"}	Аудио-воспроизведение прервано
error	{"type": "error", "message": "..."}	Ошибка

Важные особенности голосового WebSocket
1. Эксклюзивный доступ — одновременно только одно голосовое подключение. Второй клиент получит ошибку {"type": "error", "message": "Пайплайн занят другим клиентом", "code": "pipeline_locked"} и соединение закроется (код 409).
2. Формат аудио на входе: PCM float32, 16kHz, моно. Чанки по ~500мс (~8000 сэмплов).
3. Формат аудио на выходе: PCM float32, 48kHz, моно. Приходят бинарными чанками по 4096 сэмплов между audio_start и audio_end JSON-сообщениями.
4. Прерывание: отправьте {"type": "interrupt"} чтобы прервать генерацию LLM или воспроизведение аудио.
