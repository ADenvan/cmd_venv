```
    ├── validators.py           # Проверка типов, диапазонов, полупериодов
    └── formatters.py           # Форматирование ₽, дат, статус-бейджей
```
**Ключевые принципы:**
- ✅ **Zero UI-Business Coupling:** `payroll_engine.py` не импортирует `customtkinter` и `sqlite3`.
- ✅ **Strategy Pattern для типов оплаты:** `SalaryStrategy` vs `HourlyStrategy` внутри движка.
- ✅ **Хранение полупериодов:** `period_half ∈ {1, 2}` позволяет вести независимый расчёт и статус для 1-15 и 16-31.
- ✅ **Справочник норм:** Отдельная таблица `month_norms` хранит `O` (рабочие дни в месяце), исключает ручной ввод и ошибки.

### 🗄️ 2. Схема БД (SQLite)
```sql
-- Справочник сотрудников
CREATE TABLE employees (
    id INTEGER PRIMARY KEY,
    full_name TEXT NOT NULL UNIQUE,
    position TEXT,
    payment_type TEXT CHECK(payment_type IN ('salary', 'hourly')),
    base_amount REAL NOT NULL, -- оклад или часовая ставка
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Нормы рабочих дней по месяцам (Столбец O из Excel)
CREATE TABLE month_norms (
    year_month TEXT PRIMARY KEY, -- формат YYYY-MM
    norm_days REAL NOT NULL,     -- например, 22 для декабря, 17 для января
    norm_hours REAL GENERATED ALWAYS AS (norm_days * 8) STORED
);

-- Записи табеля (хранятся по полупериодам)
CREATE TABLE timesheets (
    id INTEGER PRIMARY KEY,
    employee_id INTEGER NOT NULL,
    year_month TEXT NOT NULL,
    period_half INTEGER CHECK(period_half IN (1, 2)), -- 1 = 1-15, 2 = 16-31

    -- Факт (J, K, L)
    hours_regular REAL DEFAULT 0,
    hours_evening REAL DEFAULT 0,
    hours_double REAL DEFAULT 0,

    -- Начисления и доплаты (P, Q, R...)
    premium REAL DEFAULT 0,
    supplements_travel REAL DEFAULT 0,
    supplements_senior REAL DEFAULT 0,
    supplements_other REAL DEFAULT 0,

    -- Расчётные поля
    calculated_hourly_rate REAL DEFAULT 0,
    base_earnings REAL DEFAULT 0,
    total_supplements REAL DEFAULT 0,
    recalc_amount REAL DEFAULT 0,
    total_accrued REAL DEFAULT 0,

    -- Выплаты и статус
    paid_amount REAL DEFAULT 0,
    remainder REAL DEFAULT 0,
    status TEXT DEFAULT 'draft' CHECK(status IN ('draft', 'calculated', 'approved', 'paid')),

    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (employee_id) REFERENCES employees(id),
    FOREIGN KEY (year_month) REFERENCES month_norms(year_month),
    UNIQUE(employee_id, year_month, period_half)
);
```

### ⚙️ 3. Калькулятор (`services/payroll_engine.py`)
Прямой перевод ваших Excel-формул в Python:
```python
from dataclasses import dataclass
from typing import Literal

@dataclass
class PayrollInput:
    payment_type: Literal['salary', 'hourly']
    base_amount: float      # N
    norm_days: float        # O
    hours_regular: float    # J
    hours_evening: float    # K
    hours_double: float     # L
    premium: float = 0
    supplements: float = 0
    recalc: float = 0

def calculate(input_data: PayrollInput) -> dict:
    # 1. Часовая ставка (M)
    if input_data.payment_type == 'salary':
        hourly_rate = input_data.base_amount / input_data.norm_days / 8
    else:
        hourly_rate = input_data.base_amount

    # 2. Базовый заработок
    if input_data.payment_type == 'hourly':
        # =(J+K+L)*M
        base_earnings = (input_data.hours_regular + input_data.hours_evening + input_data.hours_double) * hourly_rate
    else:
        # =(N/(O*8))*J
        base_earnings = (input_data.base_amount / (input_data.norm_days * 8)) * input_data.hours_regular

    total_supplements = input_data.premium + input_data.supplements
    total_accrued = base_earnings + total_supplements + input_data.recalc
    remainder = total_accrued - input_data.paid_amount

    return {
        "hourly_rate": round(hourly_rate, 2),
        "base_earnings": round(base_earnings, 2),
        "total_supplements": round(total_supplements, 2),
        "total_accrued": round(total_accrued, 2),
        "remainder": round(remainder, 2)
    }
```
*✅ Точно соответствует примерам Германа, Мохамеда и Вероники.*

### 📐 6. Лучшие практики для вашего стека
| Аспект | Рекомендация |
|--------|--------------|
| **Таблица в CTk** | `CustomTkinter` не имеет нативной таблицы. Используйте `ttk.Treeview` + `ttk.Style(theme="clam")` + кастомные цвета. Это стабильнее, чем сторонние `CTkTable`. |
| **Транзакции** | Все `INSERT/UPDATE` оборачивайте в `try: conn.commit() except: conn.rollback()` |
| **UI-блокировка** | При расчёте >50 строк используйте `app.after(10, update_ui)` или вынесите тяжёлые операции в `threading`, но для MVP достаточно синхронного вызова (SQLite быстрый). |
| **Валидация** | Запрещайте `norm_days == 0`, отрицательные часы, `status` вне цикла. Ошибки выводите в `CTkLabel` под полем. |
| **Типизация** | `dataclasses` для передачи данных между слоями. `mypy` на этапе 2. |
| **Безопасность** | Только параметризованные запросы `?`. Никаких `f-string` в SQL. |
