    4.2 Типы оплаты: окладник, окладник-час, по часам

## 📋 Сводка по формулам из файла:

| Тип расчёта | Формула | Описание |
|------------|---------|----------|
| **Часовая ставка** | `=N/O/8` | Оклад ÷ раб.дней в месяце ÷ 8 часов |

| **Итоговая сумма** | `=X+Y+Z` | Начислено + перерасчёт + остаток с прошлого периода |
| **Расчёт с окладом** | `=(N/(O*8))*J` | Пропорционально отработанным дням/часам |
| **Сложная формула** | `=(N/(O*8))*J+L*M` | Окладная часть + оплата сверхурочных по ставке |
