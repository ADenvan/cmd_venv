# torch
- это пакет Python, предоставляющий две основные функции:
- Вычисления тензоров (подобно NumPy) с мощным ускорением на графическом процессоре
Глубокие нейронные сети, построенные на основе системы автоматического градуирования на основе ленточных накопителей
- Вы можете повторно использовать свои любимые пакеты Python, такие как NumPy, SciPy и Cython, для расширения функционала PyTorch при необходимости.
- `pip install torch`

## torchvision
- включает в себя популярные наборы данных, архитектуры моделей и распространенные преобразования изображений для компьютерного зрения.
## torchaudio
- применить PyTorch в области обработки звука. Поддерживая PyTorch, torchaudio следует той же философии, что и PyTorch, обеспечивая мощное ускорение с помощью графического процессора.

# SileroVAD
- это модель машинного обучения для обнаружения активности голоса (Voice Activity Detection, VAD) в аудиосигналах. Она предназначена для выявления сегментов аудио, содержащих человеческую речь, и используется в различных приложениях, где требуется различение речи и неречевых сегментов.
1. Высокая точность.
    - Модель демонстрирует хорошие результаты в задачах обнаружения речи.
2. Быстрая обработка.
    - Один аудиофрагмент (более 30 мс) обрабатывается на одном CPU-потоке менее чем за 1 мс.
3. Лёгкий вес.
    - Размер JIT-модели составляет около двух мегабайт.
4. Гибкая частота дискретизации.
    - Поддерживает 8000 Гц и 16000 Гц.
5. Портативность.
    - Благодаря экосистемам PyTorch и ONNX модель работает везде, где доступны эти рантаймы.
6. Многоязычная поддержка.
    - Модель была обучена на огромных корпусах, включающих более 6000 языков
