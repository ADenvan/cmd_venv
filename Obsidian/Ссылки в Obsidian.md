
## Ссылка на файл (самое базовое)

**Wiki-ссылки** (двойные квадратные скобки):

- `[[Имя файла]]` — ссылка на файл с таким именем
- `[[Имя файла|Отображаемый текст]]` — ссылка с пользовательским текстом (алиас)

**Markdown-ссылки**:

- `[Текст](Имя файла.md)` — стандартный Markdown
- `[Текст](./Папка/Имя файла.md)` — относительный путь

> 💡 **Совет**: Если у вас несколько файлов с одинаковыми именами в разных папках, Obsidian попросит уточнить путь. Можно сразу писать: `[[Папка/Файл]]`.

## Ссылка на блок (абзац, список, цитату)
```markdown
[[Имя файла^block-id]]
```
Чтобы присвоить блоку ID:
1. Добавьте `^` и произвольный идентификатор (например, `^a1b2c3`) в конец нужного абзаца
2. Obsidian сделает это автоматически, если начать ссылку на блок через `^`

## Встраивание (Embeds) — показ контента напрямую

Добавьте `!` перед ссылкой:
```markdown
![[Заметка]]           — встраивает всю заметку
![[Заметка#Заголовок]] — встраивает только раздел
![[Заметка#^id]]       — встраивает только блок
![[image.png]]         — встраивает изображение
![[document.pdf#page=3]] — конкретная страница PDF
```



## Ссылки на папки
Obsidian не имеет встроенных ссылок на папки внутри заметок, но есть обходные пути:

### Через Obsidian URI scheme
```markdown
[Открыть папку](obsidian://open?path=Папка/Подпапка)
```
### Трюк через `file:` URL (только для локального использования)
```markdown
[Папка](file:///C:/путь/к/папке)
```
