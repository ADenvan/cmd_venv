# faster-whisper
- это переработанная версия модели Whisper от OpenAI с использованием CTranslate2, быстрого механизма вывода для моделей Transformer.
    - Использует движок CTranslate2 — высокопроизводительный движок для инференса Transformer-моделей.
- Faster Whisper — оптимизированная реализация модели Whisper от OpenAI для автоматического распознавания речи (ASR).
- `https://pypi.org/project/faster-whisper/`
- `pip install faster-whisper`
