# SciPy
- (произносится как «Сай Пай») — это программное обеспечение с открытым исходным кодом для математики, науки и техники. Оно включает модули для статистики, оптимизации, интегрирования, линейной алгебры, преобразований Фурье, обработки сигналов и изображений, решения дифференциальных уравнений и многого другого.
- `https://pypi.org/project/scipy/`
- `pip install scipy`
