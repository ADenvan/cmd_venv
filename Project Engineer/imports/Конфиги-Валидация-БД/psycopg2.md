
Psycopg — это самый популярный адаптер базы данных PostgreSQL для языка программирования Python. 
К его основным особенностям относятся полная реализация спецификации Python DB API 2.0, а также потокобезопасность (несколько потоков могут использовать одно и то же соединение).
- `https://pypi.org/project/psycopg2/`
- `pip install psycopg2`
