# pydantic
- Pydantic — библиотека для Python, предназначенная для валидации и трансформации данных. Она помогает разработчикам гарантировать, что входные данные соответствуют установленным правилам и типам, а также обеспечивает их автоматическое преобразование в нужные форматы
- `https://pypi.org/project/pydantic/`
- `pip install pydantic`
