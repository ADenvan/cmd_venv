


# 🛠️ Как это работает?
1. MCP использует архитектуру клиент–сервер:
    - MCP-клиент — это ИИ-ассистент (например, Claude Desktop, Cursor, VS Code с плагином).
    - MCP-сервер — коннектор к конкретному сервису (например, Hugging Face, GitHub, arXiv).

# 🧩 Примеры MCP-инструментов для исследований
1. Research Tracker MCP
    - автоматизирует поиск статей, кода и моделей. Доступен через настройки Hugging Face:

2. Google Scholar MCP-сервер
    — позволяет искать научные публикации по ключевым словам, авторам или цитированию.

3. arXiv + GitHub + Hugging Face связка
    — MCP может одновременно опрашивать все три платформы и строить связи между статьёй, кодом и моделью.


- mcp-perplexity
Perplexity.ai — это поисковый ИИ, который не просто возвращает ссылки, а анализирует страницы и даёт сжатый, точный, аргументированный ответ с источниками.


- arxiv-mcp
arXiv MCP Server (реальный, open-source)
    - Позволяет искать научные статьи по arXiv напрямую из ИИ-ассистента.
    - Тип: remote или stdio (если запущен локально)
    - GitHub: https://github.com/mcp/arxiv-mcp


- github-research-mcp
- `https://github.com/benjaminfh/research-mcp`
GitHub Research MCP (интеграция с GitHub API)
Ищет репозитории, код, README, issues по научным проектам.
API:
MCP-обёртка: доступна как github-research-mcp (через npm)
Подключение:


- research-tracker-mcp
    - для поиска статей и моделей,

- github-mcp
    - для поиска кода.

- chrome-devtools
