
**uv** — это современный и очень быстрый менеджер пакетов и проектов для Python, написанный на языке Rust. Его главная задача — значительно ускорить работу с зависимостями, виртуальными окружениями и версиями самого Python.

```bash
# для Windows
winget install astral-sh.uv
# Проверка наличия uv
uv --version
```

```bash
# Безопасная проверка
uv tool list
# Обновить
uv tool update-shell
```
