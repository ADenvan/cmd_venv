
**npm (Node Package Manager)** — это стандартный менеджер пакетов для Node.js. Его основная задача — устанавливать, обновлять и отслеживать зависимости проекта. Когда вы выполняете команду `npm install`, `npm` скачивает нужные пакеты и их зависимости, размещая их в папке `node_modules` , а информацию о них записывает в файл `package.json` . `npm` также позволяет запускать скрипты, определённые в `package.json` , для автоматизации задач вроде сборки или тестирования.

**npx (Node Package Execute)** — это утилита, которая поставляется вместе с npm начиная с версии 5.2.0. Её главная задача — **выполнять пакеты без их постоянной установки**. Это особенно удобно для одноразовых задач, тестирования инструментов или создания каркасов проектов.
