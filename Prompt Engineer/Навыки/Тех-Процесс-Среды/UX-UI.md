- **UX/UI в программировании** — это не отдельные технологии, а два взаимосвязанных аспекта проектирования цифровых продуктов: пользовательского опыта (User Experience, UX) и пользовательского интерфейса (User Interface, UI). Их совместная работа направлена на то, чтобы приложение, сайт или сервис были не только красивыми, но и удобными, понятными и эффективными для пользователя.
# User Experience / User Interface

1. **UX (User Experience)** — пользовательский опыт
	- **UX** охватывает весь путь взаимодействия человека с продуктом: от момента осознания потребности до достижения цели и дальнейшего взаимодействия.


2. **UI (User Interface)** — пользовательский интерфейс
	- **UI** — это визуальная и интерактивная оболочка продукта, то есть всё, с чем непосредственно взаимодействует пользователь.
