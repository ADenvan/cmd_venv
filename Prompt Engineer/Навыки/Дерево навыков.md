# Виды Навыка:
- [[Дата-аналитик (аналитик данных, Data Analyst)]] - Сбор данных - Очистка данных - Анализ - Визуализация.
- [[Наука о данных (Data Science)]] - Её цель — извлечь из данных знания, закономерности и инсайты для принятия решений, прогнозирования и автоматизации процессов. (дата-сайентист) — профессионал, который находится на стыке нескольких дисциплин: у него есть навыки программиста, знания статистика и аналитическое мышление исследователя.


- [[Системный аналитик (Systems Analyst)]] - Анализом требований к информационным системам, их формализацией и разработкой технических заданий для разработчиков

- [[Старший промпт-инженер (Senior Prompt Engineer)]] - Специалист, который занимается разработкой, тестированием, развёртыванием и постоянным улучшением промптов для больших языковых моделей (LLM)
- [[Аудитор промптов (Prompt Auditor)]] - Это инструмент или подход, направленный на проверку, анализ или улучшение запросов к искусственным интеллектам (ИИ).

- [[Архитектор программного обеспечения (Software Architect)]] - Опытный специалист, отвечающий за техническую структуру программных систем.

# Принцип разработки

- [[DRY (Don’t Repeat Yourself)]] - принцип разработки программного обеспечения, направленный на минимизацию дублирования информации в коде
- [[GRASP (General Responsibility Assignment Software Patterns)]] - для решения задач по назначению ответственностей классам и объектам.
- [[SOLID]] - это набор из пяти принципов объектно-ориентированного программирования, разработанный для улучшения структуры и читаемости кода.
- [[KISS (Keep It Simple, Stupid)]] - это принцип проектирования и разработки, который заключается в создании простых и понятных решений

- [[WebSocket]] - Сетевой протокол передачи данных, который обеспечивает постоянное двустороннее.
- [[FastAPI]] - Веб-фреймворк для создания веб-API на языке Python
