
## Структура файлов и папок

```bash
# Установите OpenCode CLI глобально:
npm install -g opencode-ai
opencode --version
# OpenCode предоставляет встроенную команду для удаления:
opencode uninstall
```

После установки OpenCode создаёт следующие файлы и папки:
```txt
%USERPROFILE%
├── .config/
│   └── opencode/
│       ├── opencode.jsonc          # Глобальная конфигурация [[22]]
│       └── opencode.json           # (устаревший формат, может быть вместо .jsonc)
│
├── .local/
│   └── share/
│       └── opencode/
│           ├── auth.json           # Данные аутентификации (API-ключи, OAuth-токены) [[22]]
│           ├── log/                # Логи приложения [[22]]
│           └── project/            # Данные сессий и сообщений по проектам [[22]]
│
└── .cache/
    └── opencode/                   # Кэш пакетов LLM-провайдеров [[22]]
```

**Пути Windows:**

- Конфигурация: `%USERPROFILE%\.config\opencode\opencode.jsonc`
- Данные сессий: `%USERPROFILE%\.local\share\opencode`
- Кэш провайдеров: `%USERPROFILE%\.cache\opencode`
