
#### Как сделать, чтобы OpenCode «видел» модели?

Чтобы OpenCode автоматически обнаруживал все модели, загруженные в LM Studio, рекомендуется использовать специальный плагин. Это избавит вас от необходимости вручную перечислять каждую модель в конфиге.

1. **Установите плагин** в вашем проекте или глобально:
```bash
npm install opencode-lmstudio
```

2. **Добавьте плагин в ваш `opencode.jsonc`** в раздел `plugin`:
```json
{
  // ... ваш конфиг ...
  "plugin": [
    // ... другие плагины ...
    "opencode-lmstudio@0.3.1" // Укажите актуальную версию
    "opencode-lmstudio@latest"
  ],
  "provider": {
    // ... настройки провайдера lmstudio ...
  }
}
```
