## 📊 Анализ строки модели
- `https://opencode.ai/docs/ru/agents/#%D0%BC%D0%BE%D0%B4%D0%B5%D0%BB%D1%8C`
Если вы не укажете модель, основные агенты будут использовать глобально настроенную модель(/docs/config#models), а субагенты будут использовать модель основного агента, вызвавшего субагент.

```json
{
  "agent": {
    "build": { // Агент режим
      "mode": "primary", // Указываем, что это основной агент
      "model": "ollama/kimi-k2.5:cloud", // Явно указываем модель nemotron-3-super-free
      "tools": {
        "write": true,
        "edit": true,
        "bash": true,
        "read": true,
        "changed-files": true
      }
    },
    "code-reviewer": {
      "description": "Expert code review specialist. Reviews code for quality, security, and maintainability. Use immediately after writing or modifying code.",
      "mode": "subagent", // под-агент
      "model": "inherit", // Можно просто указать "inherit" Аген наследует модель от родителя
      "prompt": "{file:prompts/agents/code-reviewer.txt}",
      "tools": {
        "read": true,
        "bash": true,
        "write": false,
        "edit": false
      }
    }
  }
}
```


### 🔍 Разбор значения

```json
"model": "anthropic/claude-sonnet-4-20250514"
```

| Компонент | Значение |
| --- | --- |
| `anthropic/` | Идентификатор провайдера (поставщика) модели |
| `claude-sonnet-4` | Имя конкретной модели (версия 4 Sonnet от Anthropic) |
| `20250514` | Дата релиза/обновления (2025-05-14 — май 2025 года) |

---

### 📖 Что такое Claude Sonnet?

**Anthropic Claude Sonnet** — это модель от компании Anthropic, ориентированная на производительность и точность.

| Модель | Особенности |
| --- | --- |
| `claude-sonnet-4` | Высокая точность, быстрый отклик, подходит для большинства задач |
| `claude-haiku-4` | Быстрая, дешевле, подходит для простых задач |
| `claude-opus-4` | Самая мощная, для сложных задач, дороже |

---

### 🔄 Альтернативные форматы строк

Строка модели может быть заменена на разные варианты:

#### 1\. **Простой формат** (без даты)

```json
"model": "anthropic/claude-sonnet-4"
```

Дата не обязательна — модель будет использовать последнюю версию.

#### 2\. **OpenAI модели**

```json
"model": "openai/gpt-4o"
"model": "openai/gpt-4.5"
"model": "openai/o1"
"model": "openai/o3-mini"
```

#### 3\. **Google модели**

```json
"model": "google/gemini-1.5-flash"
"model": "google/gemini-2.0-flash-exp"
"model": "google/gemini-2.0-pro-exp"
```

#### 4\. **Mistral AI модели**

```json
"model": "mistral/mistral-large-latest"
"model": "mistral/codestral-latest"
```

#### 5\. **Meta модели**

```json
"model": "meta/llama-3.1-8b"
"model": "meta/llama-3.1-70b"
"model": "meta/llama-4"
```

#### 6\. **Локальные модели**

```json
"model": "local/mistral-7b"
"model": "local/llama-3.2-3b"
```

### ⚙️ Как выбрать модель для субагента

| Сценарий | Рекомендуемая модель |
| --- | --- |
| **Аудит безопасности** | `claude-sonnet-4` или `claude-haiku-4` (низкая температура) |
| **Параллельная работа** | `claude-sonnet-4` (баланс скорости и точности) |
| **Поиск кода** | `claude-haiku-4` (быстрая, для чтения) |
| **Сложные задачи** | `claude-opus-4` или `gpt-4.5` |
| **Локальная работа** | `llama-3.1-70b` (если есть мощная видеокарта) |
| **Мультимедиа** | `gemini-2.0` |

### ⚠️ Важные замечания

1.  **Проверьте конфигурацию API ключей** — в `~/.config/opencode/api-key.json` должен быть ключ для выбранного провайдера
2.  **Обновляйте модели** — новые версии моделей (без даты) обычно имеют последние улучшения
3.  **Локальные модели** — требуют настройки пути к модели в конфигурации
4.  **Тестирование** — после изменения модели лучше протестировать субагент на простых задачах

### 📝 Примеры использования

#### Быстрый и дешёвый (Explore субагент)
```json
"model": "anthropic/claude-haiku-4"
```

#### Оптимальный выбор (General субагент)
```json
"model": "anthropic/claude-sonnet-4"
```

#### Мощный, но дорогой (Security Auditor)
```json
"model": "anthropic/claude-opus-4"
```

#### Универсальный OpenAI
```json
"model": "openai/gpt-4o"
```

### 🎯 Рекомендация для начала
**Начните с** `claude-sonnet-4` — это лучший баланс между ценой, скоростью и качеством. Если задачи простые — переходите на `haiku-4`, если нужны максимум возможности — `opus-4`.
Для локальной работы — настройте `llama-3.1-70b` или аналогичную локальную модель.
