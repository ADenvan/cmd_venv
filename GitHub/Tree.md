# agentic
- Работает как расширении к opencode
    agentic.json работает так:
    - ✅ Хранит путь к thoughts/ директории
    - ✅ Хранит модель AI для sub-агентов по умолчанию
    - ✅ Используется командами /ticket, /research, /plan и т.д.
    - ✅ Читается через agentic config CLI
- Установка bun в колн проекте
    ⚡ Быстрый способ (без прав администратора):
    1. Win + R → sysdm.cpl → Enter
    2. Вкладка "Дополнительно"
    3. Кнопка "Переменные среды"
    4. В разделе "Переменные среды пользователя для ваше имя"
    5. Найдите переменную Path → Изменить → Создать
    6. Добавьте: D:\Python-Project\GitHub\agentic\bin
    7. ОК → ОК → ОК
    После этого откройте новое окно CMD/PowerShell и проверьте:
    agentic --version
