**Основные принципы проектирования для создания поддерживаемого и пригодного к тестированию кода на Python.**

1. Рассматриваются пять ключевых принципов: KISS (принцип простоты), принцип единственной ответственности, разделение задач (Separation of Concerns), композиция вместо наследования и «правило трех».
2. Приводятся практические примеры кода, демонстрирующие противопоставление антипаттернов рекомендуемым подходам для каждого принципа.
3. Даются рекомендации по построению многоуровневой архитектуры (слои API, сервисов и репозиториев) и использованию паттернов внедрения зависимостей для обеспечения тестируемости.
4. Делается акцент на явном и читаемом коде в противовес преждевременной абстракции, а также предлагаются рекомендации по управлению размером и сложностью функций.
