# SQLite Viewer
1. Работает на любой платформе без привязки к родным библиотекам — открывается даже в VS Code для веб-версии.
- Удобство использования
    - Открытие файлов .sqlite или .db одним кликом — автоматически запускается редактор.
    - Быстрый и интуитивно понятный интерфейс с виртуализированной прокруткой, сортировкой и фильтрацией данных.

2. Интеграция
- Полностью совместим с VS Code, поддерживает темы и цветовые схемы пользователя.
- Ограничения
    - Данные только для чтения и кэшируются.
    - Поддерживаются файлы до 2 ГБ, загружаемые в оперативную память.
    - Нет возможности запускать SQL-запросы напрямую.
3. Дополнительно
- Доступно платное расширение с расширенными функциями и спонсируемым контентом.

# Django Template Support
Функционал:
1. Синтаксическая подсветка кода;
2. Синтаксическая подсветка для HTML, CSS и JavaScript;
3. Автоматическое форматирование и улучшение читаемости кода;
4. Автодополнение для тегов HTML, атрибутов, CSS-правил и JavaScript;
5. Подсказки по исправлению ошибок и улучшению структуры;
6. Форматирование через Prettier с автоматической настройкой из конфигов (.prettierrc, .prettier.json и др.), включая поиск в родительских директориях.
По умолчанию поддерживаются связанные файлы для шаблонов Django (.django, .dj).

# HTML CSS Support
1. HTML атрибуты id и class для Visual Studio Code.
- Функции
    - Автодополнение атрибутов id и class HTML
    - Поддержка автодополнения из стилей, определенных в файле
    - Поддержка указания удаленных и локальных таблиц стилей
    - Поддержка любого языка для автодополнения
    - Поддержка перехода к определению селекторов
    - Проверка атрибутов класса по запросу
- Поддерживаемые языки можно настроить с помощью глобального параметра css.enabledLanguages. По умолчанию включен html:
{
"css.enabledLanguages": ["html"]
}
- Расширение можно настроить для поддержки любого языка, где это имеет смысл, например, nunjucks, twig, mustache, vue, typescript и т.д. Также следует установить соответствующее языковое расширение, которое регистрирует конкретный идентификатор языка в VS Code.
