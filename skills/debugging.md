# Дерево мыслей (Tree of Thought): выбор гипотезы
**Методология:** Формируем несколько гипотез, проверяем параллельно и выбираем лучшую ветку

## Корневая проблема
**Проблема:** Как ускорить поставку фичи без потери качества?

## Ветви гипотез
| Ветка | Гипотеза | Проверка | Оценка |
|-------|----------|----------|--------|
| **A** | Быстрый патч | Риск регрессий | 4.7/10 |
| **B** | Глубокий рефакторинг | Стоимость внедрения | 6.2/10 |
| **C** | Модуль + тесты | Баланс времени/качества | 9.1/10 |

## Результат
**Выбрано:** Ветка C (Модуль + тесты) — наилучший баланс критериев

# Скиллы-фреймворки и оркестрация

- `https://github.com/obra/superpowers`
**Архитектура:** Последовательные этапы + параллельные дорожки + общий контроль качества

## Последовательные этапы (Планирование)

| Этап | Описание |
|------|----------|
| **Discovery** | Контекст и ограничения |
| **Spec** | Критерии и интерфейсы |
| **Plan** | Пакет задач и зависимости |

## Параллельные дорожки (Исполнение)

| Субагент | Сцена | Задачи |
|----------|-------|--------|
| **Subagent A** | Сцена 17 | Build → Validate → Simplify |
| **Subagent B** | Сцена 18 | Build → Validate → Simplify |
| **Subagent C** | Сцена 19 | Build → Validate → Simplify |

## Ключевые принципы
1. Последовательность на уровне планирования (Discovery → Spec → Plan)
2. Параллелизм на уровне исполнения (Subagent A/B/C)
3. Унификация процессов (Build → Validate → Simplify)
4. Общий контроль качества
