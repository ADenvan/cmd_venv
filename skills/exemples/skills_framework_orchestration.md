# Скиллы-фреймворки и оркестрация

**Архитектура:** Последовательные этапы + параллельные дорожки + общий контроль качества

---

## Этап 1: Последовательные этапы (Верхний уровень)

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  Discovery  │ ──▶ │    Spec     │ ──▶ │    Plan     │
│             │     │             │     │             │
│ контекст и  │     │ критерии и  │     │ пакет задач │
│ ограничения │     │ интерфейсы  │     │ и зависимости│
└─────────────┘     └─────────────┘     └─────────────┘
```

| Этап | Описание |
|------|----------|
| **Discovery** | Контекст и ограничения |
| **Spec** | Критерии и интерфейсы |
| **Plan** | Пакет задач и зависимости |

---

## Этап 2: Параллельные дорожки (Нижний уровень)

После планирования запускаются параллельные субагенты:

```
┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│   Subagent A    │  │   Subagent B    │  │   Subagent C    │
│     Сцена 17    │  │     Сцена 18    │  │     Сцена 19    │
│                 │  │                 │  │                 │
│  • Build        │  │  • Build        │  │  • Build        │
│  • Validate     │  │  • Validate     │  │  • Validate     │
│  • Simplify     │  │  • Simplify     │  │  • Simplify     │
└─────────────────┘  └─────────────────┘  └─────────────────┘
         │                    │                    │
         └────────────────────┼────────────────────┘
                              │
                              ▼
                    [Общий контроль качества]
```

| Субагент | Сцена | Задачи |
|----------|-------|--------|
| **Subagent A** | Сцена 17 | Build → Validate → Simplify |
| **Subagent B** | Сцена 18 | Build → Validate → Simplify |
| **Subagent C** | Сцена 19 | Build → Validate → Simplify |

## Полная схема процесса

```
ВХОД
  │
  ▼
┌─────────────┐
│  Discovery  │ ──▶ Определение контекста и ограничений
└─────────────┘
  │
  ▼
┌─────────────┐
│    Spec     │ ──▶ Формирование критериев и интерфейсов
└─────────────┘
  │
  ▼
┌─────────────┐
│    Plan     │ ──▶ Создание пакета задач и зависимостей
└─────────────┘
  │
  ├──────────────┬──────────────┐
  ▼              ▼              ▼
┌─────────┐  ┌─────────┐  ┌─────────┐
│Subagent │  │Subagent │  │Subagent │
│   A     │  │   B     │  │   C     │
│Сцена 17 │  │Сцена 18 │  │Сцена 19 │
└─────────┘  └─────────┘  └─────────┘
  │              │              │
  └──────────────┴──────────────┘
                 │
                 ▼
        [Контроль качества]
                 │
                 ▼
              ВЫХОД
```

---

## Ключевые принципы

1. **Последовательность на уровне планирования** — Discovery → Spec → Plan
2. **Параллелизм на уровне исполнения** — независимые субагенты работают одновременно
3. **Унификация процессов** — все субагенты следуют одинаковому циклу: Build → Validate → Simplify
4. **Централизованный контроль качества** — объединение результатов всех субагентов
