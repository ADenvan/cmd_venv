## Сравнение подходов

| Copy + Trust | Reuse + Customize |
|--------------|-------------------|
| Слепое копирование универсальных правил | Адаптация под контекст |
| Избыточность (6+ элементов) | Фокус (4 релевантных) |
| Конфликты с проектной спецификой | Полная совместимость |
