# Дебаггинг как структурированный пайплайн

**Процесс:** Логи -> воспроизведение -> изоляция -> гипотеза -> фиксация, только после подтверждения шага

---

## Пайплайн отладки

### Шаг 1: Собрать логи
- **Статус:** ✅ ОК
- **Результат:** Контекст зафиксирован

### Шаг 2: Воспроизвести баг
- **Статус:** ✅ ОК
- **Результат:** Ошибка повторяется

### Шаг 3: Изолировать зону
- **Статус:** ✅ ОК
- **Результат:** Причина сужена

### Шаг 4: Проверить гипотезу
- **Статус:** ✅ ОК
- **Результат:** Подтверждение получено

### Шаг 5: Зафиксировать fix
- **Статус:** ✅ ОК
- **Результат:** Регрессия покрыта

---

## Визуальная структура процесса

```
[Шаг 1]        [Шаг 2]        [Шаг 3]        [Шаг 4]        [Шаг 5]
Собрать логи   Воспроизвести  Изолировать    Проверить      Зафиксировать
               баг            зону           гипотезу       fix
     |               |               |               |               |
     └───────────────┴───────────────┴───────────────┴───────────────┘

Контекст       Ошибка         Причина        Подтверждение  Регрессия
зафиксирован   повторяется    сужена         получено       покрыта
```

## Последовательность выполнения

1. **Сбор логов** → Фиксация контекста
2. **Воспроизведение** → Подтверждение повторяемости ошибки
3. **Изоляция** → Сужение области поиска причины
4. **Проверка гипотезы** → Получение подтверждения причины
5. **Фиксация** → Покрытие регрессией
