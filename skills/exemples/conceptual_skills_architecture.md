## Структура уровней

| Уровень | Название | Содержимое | Границы |
|---------|----------|------------|---------|
| **Level 4** | SYSTEM | Вся система | Внешняя рамка |
| **Level 3** | MODULE BOUNDARY | Граница модуля | Средняя рамка |
| **Level 2** | SERVICE LAYER | Сервисный слой | Внутренняя рамка |
| **Level 1** | file.ts | Конкретный файл | Центральный элемент |

---

## Компоненты и интерфейсы

### Центральный элемент
- **file.ts** — конкретный файл, точка входа

### Внешние модули (вне SERVICE LAYER, внутри MODULE BOUNDARY)

| Модуль | Интерфейс | Направление |
|--------|-----------|-------------|
| **API module** | `interface: request-contract` | file.ts → API module |
| **Data module** | `interface: data-contract` | file.ts ↔ Data module |

### Связи
- **API module** — связь через request-contract (односторонняя от file.ts)
- **Data module** — связь через data-contract (двусторонняя)

---

## Принцип Zoom-out

**Последовательность масштабирования:**

```
file.ts ──▶ SERVICE LAYER ──▶ MODULE BOUNDARY ──▶ SYSTEM
 (файл)        (сервис)           (модуль)          (система)
   │              │                   │                 │
   └──────────────┴───────────────────┴─────────────────┘
                    Контекст растет
```

1. **file.ts** — начинаем с конкретного файла
2. **SERVICE LAYER** — видим слой сервисов, к которому принадлежит файл
3. **MODULE BOUNDARY** — выходим на уровень модуля с его границами
4. **SYSTEM** — достигаем системного уровня с внешними модулями

## Архитектурные паттерны

| Паттерн | Реализация |
|---------|------------|
| **Вложенность** | 4 уровня вложенности (матрешка) |
| **Интерфейсы** | Контракты между слоями |
| **Модульность** | Четкие границы MODULE BOUNDARY |
| **Разделение ответственности** | API module ≠ Data module |

---

## Применение концептуальных скиллов

**Контекстно-зависимый выбор скилла:**

- На уровне **file.ts** — скиллы работы с кодом файла
- На уровне **SERVICE LAYER** — скиллы сервисной архитектуры  
- На уровне **MODULE BOUNDARY** — скиллы модульного дизайна
- На уровне **SYSTEM** — скиллы системной интеграции
