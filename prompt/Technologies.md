# Дата-аналитик (аналитик данных, Data Analyst)
1. Сбор данных
    - аналитик получает информацию из разных источников: баз данных, CRM-систем, сайтов, приложений или даже внешних исследований.
2. Очистка данных
    - удаляет ошибки, дубликаты и «мусор», чтобы данные были пригодны для анализа.
3. Анализ
    - использует инструменты вроде Excel, SQL, Python или BI-систем (например, Tableau или Power BI) для поиска закономерностей и трендов.
4. Визуализация
    - создаёт графики, дашборды и отчёты, чтобы результаты были понятны коллегам и руководству.
5. Коммуникация
    - объясняет свои выводы команде, предлагает решения и отвечает на вопросы бизнеса.

*Навыки*
- языки программирования (Python, R, SQL) для обработки и анализа данных;
- статистика и математика — понимание вероятностей, корреляций, регрессий и других методов;
- инструменты визуализации (Tableau, Power BI, Matplotlib) для создания наглядных отчётов;
- работа с базами данных — знание реляционных и нереляционных СУБД;
- ETL-процессы — умение извлекать, трансформировать и загружать данные;
- машинное обучение — базовое понимание алгоритмов и методов (особенно для продвинутых позиций).

# Системный аналитик
- Занимается анализом требований к информационным системам, их формализацией и разработкой технических заданий для разработчиков.
--------------------------------------------
# Аналитик изображений
- специалист, который занимается анализом изображений, извлечением из них информации, идентификацией объектов, сцен или характеристик.
- Сбор информации.
    - Аналитик получает данные из разных источников — неподвижных и движущихся изображений.
- Обработка изображений.
    - Включает компиляцию, кодирование, категоризацию, вычисления, систематизацию данных в таблицы, проведение аудитов и проверку информации.
- Анализ данных.
    - Использование методов машинного обучения, глубокого обучения, растрового анализа и других техник для извлечения полезной информации.
- Интерпретация результатов.
    - Формулирование выводов на основе проведённого анализа.
- Коммуникация.
    - Передача результатов коллегам, руководителям или другим заинтересованным сторонам.

# Senior Prompt Engineer
- это специалист, который занимается разработкой, тестированием, развёртыванием и постоянным улучшением промптов для больших языковых моделей (LLM)
1. Проектирование промптов и стратегий контекста.
    - Разработка шаблонов промптов,
2. Определение стандартов и паттернов в промтинге.
    - Установление стандартов для инженерии промптов
3. Сотрудничество с Product и UX. Формирование поведения ИИ-функций
4. Определение стратегии оценки LLM-функций.
    - Установление метрик успеха, порогов принятия решений,
5. Влияние на выбор модели и маршрутизацию.
    - Оптимизация качества,
6. Создание повторно используемых промптов и контекстных «примитивов»
    - (например, паттерны использования инструментов),

# Аудитор промптов
- это инструмент или подход, направленный на проверку, анализ или улучшение запросов к искусственным интеллектам (ИИ).

1. Системный аудитор промптов (САП)
    - инструмент, который механически проверяет пользовательские промпты на внутренние противоречия,
2. Требовательный аудитор» в промптах
    - роль, при которой нейросеть выступает в качестве строгого проверяющего, ищущего уязвимости, несоответствия нормам, двусмысленности,
3. Инструменты для аудита промптов
    - программные решения, которые анализируют промпты на предмет безопасности,

# DRY (Don’t Repeat Yourself)
- принцип разработки программного обеспечения, направленный на минимизацию дублирования информации в коде

- Централизация логики.
    - Повторяющиеся фрагменты кода
- Переиспользование компонентов.
    - Общие части кода можно выносить в отдельные модули
- Использование классов и наследования.
    - переиспользуемые компоненты с общей функциональностью.
- Централизация констант и конфигураций.
    - Если определённые константы или настройки повторяются, их стоит вынести в один источник.
- Модульность.
    - Код разбивают на компоненты,

# GRASP
- (General Responsibility Assignment Software Patterns)
- это набор шаблонов проектирования, используемых в объектно-ориентированном проектировании для решения задач по назначению ответственностей классам и объектам. Они помогают структурировать систему, делая её более понятной, гибкой, масштабируемой и удобной в поддержке.
--------------------------------------------
# SOLID
- это набор из пяти принципов объектно-ориентированного программирования, разработанный для улучшения структуры и читаемости кода. Аббревиатура расшифровывается как:
S — Single Responsibility Principle (принцип единственной ответственности);
O — Open-Closed Principle (принцип открытости/закрытости);
L — Liskov Substitution Principle (принцип подстановки Барбары Лисков);
I — Interface Segregation Principle (принцип разделения интерфейса);
D — Dependency Inversion Principle (принцип инверсии зависимостей).

--------------------------------------------
# KISS
- это принцип проектирования и разработки, который заключается в создании простых и понятных решений, избегая избыточной сложности. Аббревиатура расшифровывается как Keep It Simple, Stupid
1. Создавать небольшие методы.
    - В идеале метод должен содержать не более 30–50 строк кода и решать одну конкретную задачу.

# Стек (stack)
- структура данных, которая работает по принципу «последним пришёл, первым ушёл» (LIFO — last in, first out).
--------------------------------------------
# AS-IS
- (от англ. as is — «как есть») — это модель, которая описывает текущее состояние бизнес-процессов в организации. Она фиксирует, как процессы работают в реальности, а не так, как записано в регламентах или представляется руководству.\

1. Цель AS-IS
    - понять реальную работу процессов, выявить узкие места, дублирование шагов, потери времени и ресурсов, а также подготовить основу для оптимизации.
2. Избегать избыточной сложности.
    - Не использовать лишние условия, вложенные циклы, излишнюю «ветвистость» кода.

# Node.js
- это кросс-платформенная среда выполнения JavaScript с открытым исходным кодом. Она позволяет запускать JavaScript-код не только в браузере, но и на сервере.
- Платформа основана на движке V8, который компилирует JavaScript в машинный код. Это превращает JavaScript из узкоспециализированного языка в язык общего назначения.
--------------------------------------------
# WebSocket
- сетевой протокол передачи данных, который обеспечивает постоянное двустороннее (full-duplex) соединение между клиентом и сервером через одно TCP-соединение. Главная особенность — поддержка актуальности соединения без новых запросов от клиента.
1. Принцип работы WebSocket:
    - WebSocket-handshake — «рукопожатие» клиента и сервера. Клиент отправляет HTTP-запрос с заголовком Upgrade, который сообщает о намерении перейти на Websocket.
2. Обмен данными.
    - Если «рукопожатие» прошло успешно, устанавливается постоянное двустороннее соединение.
- Соединение, установленное с помощью WebSocket, сохраняется до тех пор, пока его не прервёт любой из участников.
--------------------------------------------
# FastAPI
- веб-фреймворк для создания веб-API на языке Python, ориентированный на высокую производительность и простоту использования. Подходит для создания RESTful API, GraphQL API и других типов веб-сервисов.
